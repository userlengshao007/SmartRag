SmartRag 本地运行与故障区分（评测资料 v1）
本资料用于解释服务边界，不包含真实凭据，也不宣称某个端口在所有电脑上都固定归某个进程。运行地址与证书配置必须以实际部署为准。

启动前端
前端 package.json 位于 frontend 目录，应在该目录执行 pnpm run dev。默认开发端口是 9527，后端 API 常用本地端口为 8081。根目录的 pom.xml 是 Maven 后端构建文件，不能因为在根目录执行前端脚本失败就判断 Vue 项目坏了。zsh 提示 command not found: pnpm 表示命令未安装或不在 PATH，发生在读取项目脚本之前。

包管理与证书
UNABLE_TO_GET_ISSUER_CERT_LOCALLY 表示 HTTPS 证书链无法验证，不是 JavaScript 依赖语法错误。更换镜像未必解决相同的证书信任问题。应检查代理、Node 的证书信任配置和 CA 文件。保留证书校验，只有确认信任来源后才能补充 CA；不应为方便而长期设置 strict-ssl=false。本资料不承诺某个镜像永远可达，也不提供绕过完整性验证的安装方法。

Elasticsearch 连接
Elasticsearch 地址由主机、端口和 HTTP/HTTPS 协议共同决定。Unrecognized SSL message, plaintext connection? 常见于用 HTTPS 请求普通 HTTP 服务，但只改 scheme 仍可能连到错误服务。收到 text/plain 或 HTML 的 404，需要确认目标端口到底是不是 Elasticsearch。不能从默认端口 9200 推断该端口一定是 ES，也不能把所有 404 归为 mapping 字段错误。

认证响应
HTTPS 返回 JSON 格式的 401，说明已收到能识别的认证响应，但不等于用户名密码正确。数据库、Elasticsearch 与网站登录使用不同凭据。MySQL 报 using password: NO 表示客户端没有发送密码；using password: YES 则只表示发过密码，不代表密码正确。不要把项目管理员密码填写到数据库连接密码栏来试图解决认证错误。

知识库验收
源资料默认路径是 docs/smartrag.pdf，另有 docs/smartrag.md 文字说明；默认路径不证明资料已入库。自动引导入库由配置开关控制，实际也可能由管理员手动上传。要看知识库处理完成状态和真实检索原文。旧的单块简介不足以代表大型知识库的检索难度，评测时可增加多主题文档、相似干扰资料和有边界条件的问题。

记录与报告
评测报告默认目录为 eval-reports，外部题目目录默认是 eval-datasets。页面显示最近任务，已完成报告可以从磁盘恢复；运行中或失败任务的内存状态不会因为重启自动重建。报告包含生成时的资料片段，因此不应把报告当作可以随意公开的纯数字统计。备份和共享时需要遵循原文档权限。

对比的纪律
如果一轮改了资料、账号、模型、TopK 和分块方式，结果变化难以归因。推荐同一测试集固定主要条件，一次只改变一个因素；更改分块后先重建受影响文档。新旧记录可用于比较，但还应检查具体题目从对变错或从错变对的原因。没有实际实验就不能编造吞吐量、延迟分位数、可用性或生产成本承诺。
