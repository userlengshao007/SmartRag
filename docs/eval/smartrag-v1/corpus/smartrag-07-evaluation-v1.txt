SmartRag 离线评测规则与指标（评测资料 v1）
本资料是评测模块的使用契约，不包含任何题目标准答案列表。评测结果应结合样本覆盖、资料范围和人工复核一起解释，不能只展示一个漂亮百分比。

数据集
JSONL 每个非注释行是一道题。question 与 referenceAnswer 必填，id 在同一测试集中必须唯一；缺省 id 时按行号生成。expectedFileNames 或 expectedFileMd5s 指定期望文件，expectedEvidence 保存分块原文中的证据短语。没有标注期望文件的题只评回答，不进入检索命中率分母。未标注不自动等于无答案，真正的无答案题需要人工确认。

相关证据规则
有证据短语标注时，相关结果必须文件匹配并包含任意一个证据短语。匹配进行 NFKC、空白去除和大小写归一化。文件名不匹配，即使正文出现关键词也不能命中。未填 expectedEvidence 时，同一期望文件的任意分块都算相关，文件级命中会比严格的分块级判断宽松。

命中率与排名
recallAtK 在本项目中实际是 Hit Rate@K：前 K 条中出现至少一个相关分块的标注题比例。它不是召回了全部相关分块的比例。MRR 对每道标注题取第一条相关分块排名的倒数，再求平均；第一名为 1，第二名为 1/2，未找到为 0。docRecallAtK 只看是否找到期望文件，不能证明答案所在段落出现过。

回答与评委
完整评测先生成回答，再调用 LLM 评委。评委输入包括问题、参考答案、实际回答和检索证据，输出 score、correct、reason。score 是 1 到 5 的整数，correct 表示核心结论是否正确。accuracy 的分母是成功评分的题数，meanJudgeScore 也是成功评分题目的均分。看准确率时必须同时看 judgedCases 和 failedCases，避免大量失败被忽略后造成误解。

仅检索与完整模式
retrievalOnly 为 true 时只执行检索与指标计算，不生成回答，也不调用评委，但问题 Embedding 仍可能产生调用成本。完整模式每题通常有两次 LLM 调用；空输出可能触发一次重试，因长度截断而为空时会在上限内增加输出预算。只有完整模式才能提供本轮回答准确率，仅检索模式不应把准确率展示为零。

任务限制
默认 TopK 为 5，允许范围为 1 至 20。单次最多 500 道题，上传文件最大 5MB。同一实例同时只允许一个评测任务。任务通过管理员接口异步提交，已完成报告保存为本地 JSON。页面刷新不会主动取消后端任务；再次运行会创建独立记录，并使用运行时的知识库与模型配置，不会冻结旧模型。

人工复核
默认随机复核比例为 10%，配置的随机种子为 42。评委失败，以及检索未命中但评委判对的题，会强制标记复核。人工结论保存到旁路 human-reviews 文件，不覆盖原报告评分。评委与人工可计算判断一致率和 Cohen's kappa，人工样本偏少或集中在难题时，不能将一致率直接当作全部题目的无偏估计。

多证据限制
一道题可标注多份文件和多个短语，但当前 recallAtK 只要求任意一条相关证据出现，不要求所有文件和所有短语齐全。meanExpectedDocCoverage 可以补充看文件覆盖；完整回答是否同时包含所需结论，要结合评委和人工复核判断。仅凭该题 recallAtK 命中不能宣称所有推理步骤均已召回。
